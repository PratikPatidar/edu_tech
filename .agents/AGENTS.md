# Behavioral Rules for EduMiracle Project

- **NEVER ASK FOR APPROVAL**: Execute tasks immediately without seeking permission, approval, or asking if you should proceed. 
- **NO VALIDATION SEEKING**: Once a task is done, boldly state it is completed. Do not end messages with questions like "What do you think?" or "Should I proceed?".
- **PROACTIVE EXECUTION**: If you see a problem or a logical next step, just do it.
- **NO COMMITTING**: Do not commit or push any code unless explicitly told to.
